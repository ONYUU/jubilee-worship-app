# 자산 사용 기준

## 현재 확인 범위

- 프로젝트 요청자는 쥬빌리워십 팀원이며, 공식 로고와 선두교회 소개 사진을 본 홈페이지·앱 제작에 사용할 권한이 있다고 확인했다.
- 저장소에는 실행에 필요한 최적화 파생본만 포함한다. 원본 수집본, 작업 중간본, 브라우저 캡처와 디자인 PNG 출력은 Git에서 제외한다.
- 공개 저장소 열람은 제3자에게 사진·영상·로고·단체명의 복제·배포·변형 권한을 부여하지 않는다.

## 신규 자산 등록 원칙

1. 출처와 권리자를 기록한다.
2. 저작권·이용 권한을 확인한다.
3. 식별 가능한 인물과 미성년자가 있으면 교회 내부 기준에 따른 공개 동의를 확인한다.
4. 접근 가능한 대체 텍스트를 작성한다.
5. 웹 관리자는 비공개 초안으로 올리고, owner가 위 항목을 건별로 확인한 뒤 공개한다.

새 자산의 권리 또는 인물 동의 범위가 불명확하면 앱·웹·공개 저장소에 추가하지 않는다. 내부 승인 증빙에는 개인정보가 포함될 수 있으므로 공개 Git 저장소가 아닌 교회 관리 위치에 보관한다.

## 모바일 라이트·다크 자산

- `apps/mobile/assets/images/jubilee/app-icon-sky.png`, `splash-light-title.png`, `splash-dark-title.png`는 2026-08-19 OpenAI 이미지 생성 도구로 이 프로젝트를 위해 만든 시작 화면용 추상 자산이다. 타사 로고·인물·사진을 포함하지 않으며, 스플래시에는 일반 한글 제목 `쥬빌리워십`만 사용한다.
- 설치 아이콘은 검수된 공식 로고를 사용한다. `app-icon-official.png`는 공식 1024px 잠금본을 그대로 복사한 불투명 원본이고, `app-icon-official-foreground.png`와 `app-icon-official-monochrome.png`는 Android 마스크 안전영역에 맞춰 로고 모양을 바꾸지 않고 투명 여백과 단색 표현만 적용한 파생본이다.
- 앱 화면은 Instagram의 사진 중심 정보 계층을 참고했지만 Instagram 로고·상표·고유 아이콘·화면 캡처를 복제하지 않는다.
- `gallery-worship-01.webp`, `guide-community-02.webp`는 위 사용 권한이 확인된 선두교회 소개 사진의 앱 최적화본이다. 생성형 이미지로 인물이나 배경을 바꾸지 않았다.
- 2026-08-20 프로젝트 요청자는 `gallery-worship-01.webp`를 앱 홈 첫 화면에 공개 사용하는 안을 선택하고 공개 적용에 동의했다. 앱은 원본 장면을 재생성하거나 인물을 변형하지 않고 `cover` 크롭과 가독성용 오버레이만 사용한다.
- 2026-08-20 프로젝트 요청자는 별도로 제공한 예배 무대 사진을 앱과 홈페이지 홈 Hero에 적용하도록 요청했으며, 촬영자의 앱·홈페이지 공개 이용 허락과 식별 가능한 인물(미성년자가 있다면 보호자 포함)의 공개 동의가 확보됐다고 확인했다. 원본 JPEG는 Git에 포함하지 않고, 메타데이터를 제거한 `hero-home-stage-20260820-desktop-1280x720.webp`, `hero-home-stage-20260820-mobile-672x840.webp`, 앱 번들용 동일 파생본만 사용한다. 허용 변형은 확정된 화면비 크롭·크기 최적화·가독성 오버레이로 제한하며, 관련 확인 기록과 동의 증빙은 공개 저장소가 아닌 운영 위치에서 관리한다.
- 목업 보드 안의 합성 사진·문자·아이콘은 방향 확인에만 사용하고 앱 자산으로 추출하지 않는다.
