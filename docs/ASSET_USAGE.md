# 자산 사용 기준

## 현재 확인 범위

- 프로젝트 요청자는 쥬빌리워십 팀원이며, 공식 로고와 선두교회 소개 사진을 본 홈페이지·앱 제작에 사용할 권한이 있다고 확인했다.
- 저장소에는 실행에 필요한 최적화 파생본만 포함한다. 원본 수집본, 작업 중간본, 브라우저 캡처와 디자인 PNG 출력은 Git에서 제외한다.
- 공개 저장소 열람은 제3자에게 사진·영상·로고·단체명의 복제·배포·변형 권한을 부여하지 않는다.

## 신규 자산 등록 원칙

1. 출처와 권리자를 기록한다.
2. 저작권·이용 권한을 확인한다.
3. 식별 가능한 인물과 미성년자가 있으면 교회 내부 기준에 따른 공개 동의를 확인한다.
4. 접근 가능한 대체 텍스트를 작성한다.
5. 웹 관리자는 비공개 초안으로 올리고, owner가 위 항목을 건별로 확인한 뒤 공개한다.

새 자산의 권리 또는 인물 동의 범위가 불명확하면 앱·웹·공개 저장소에 추가하지 않는다. 내부 승인 증빙에는 개인정보가 포함될 수 있으므로 공개 Git 저장소가 아닌 교회 관리 위치에 보관한다.

## 모바일 라이트·다크 자산

- `apps/mobile/assets/images/jubilee/app-icon-sky.png`, `splash-light-title.png`, `splash-dark-title.png`는 2026-08-19 OpenAI 이미지 생성 도구로 이 프로젝트를 위해 만든 추상 자산이다. 타사 로고·인물·사진을 포함하지 않으며, 스플래시에는 일반 한글 제목 `쥬빌리워십`만 사용한다.
- 앱 화면은 Instagram의 사진 중심 정보 계층을 참고했지만 Instagram 로고·상표·고유 아이콘·화면 캡처를 복제하지 않는다.
- `gallery-worship-01.webp`, `guide-community-02.webp`는 위 사용 권한이 확인된 선두교회 소개 사진의 앱 최적화본이다. 생성형 이미지로 인물이나 배경을 바꾸지 않았다.
- 목업 보드 안의 합성 사진·문자·아이콘은 방향 확인에만 사용하고 앱 자산으로 추출하지 않는다.
