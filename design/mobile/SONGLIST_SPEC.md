# 이번 주 워십 송리스트 기능

## 목적

예배 참석자가 예배 전에 찬양 순서를 확인하고, 승인된 공식 음원이나 영상으로 미리 들을 수 있도록 한다.

## 사용자 흐름

1. 홈에서 이번 주 예배 순서의 1~3번 곡을 바로 확인하고 `전체 보기`를 누른다.
2. 또는 `예배 → 해당 예배 → 이번 주 워십 송리스트`로 들어간다.
3. 곡 순서, 곡명, 아티스트를 확인한다.
4. 등록된 경우 곡별 공식 링크 또는 공식 재생목록을 연다.
5. 송리스트를 공유하거나 공개 알림을 설정한다.

하단 메뉴는 `홈 · 예배 · 미디어 · 안내` 4개를 유지한다. 송리스트는 예배에 포함되는 상세 기능이다.

## 공개 정보

- 연결된 예배 날짜·시간·장소
- 곡 순서
- 곡명
- 아티스트 또는 원곡 정보
- 승인된 공식 음원·영상 링크
- 마지막 공개·수정 시각
- 현장 상황에 따라 변경될 수 있다는 안내

## 공개 상태

- `초안`: 관리자만 확인
- `확정`: 공개 가능
- `변경`: 수정 사실 표시
- `미공개`: 사용자에게 목록 대신 준비 중 화면 표시
- `취소된 예배`: 홈에서 제외하고 예배 상세에 취소 상태 표시

## 관리자 운영

- 기존 웹 관리자에서 예배를 선택한 뒤 곡을 순서대로 등록한다.
- 공개 전 예배팀 확인 절차를 거친다.
- 곡 순서 변경은 드래그 또는 번호 입력으로 처리한다.
- 공식 링크가 없는 곡은 링크 없이 제목과 아티스트만 공개할 수 있다.
- 관리자 저장만으로 즉시 공개하지 않고 `확정 후 공개`를 별도로 실행한다.

## 1차 제외 범위

- 가사 전문
- 악보 파일
- 음원 파일 직접 업로드·다운로드
- 승인되지 않은 유튜브 영상이나 개인 채널 링크
- 사용자가 송리스트를 수정하거나 곡을 요청하는 기능

가사·악보·음원은 권리 확인 전 앱에서 직접 제공하지 않는다.

## 화면 상태

- 공개 완료: 곡 목록과 공식 듣기 링크 표시
- 준비 중: 홈과 상세 화면에 `이번 주 송리스트를 준비하고 있습니다`와 공개 알림 버튼 표시
- 예정 예배 없음: `현재 확정된 예배가 없습니다`와 예배 일정 버튼 표시
- 불러오기 실패: 오류 안내와 다시 시도 버튼 표시

## 현재 시안 주의사항

현재 디자인의 `첫 번째 곡 제목` 등은 화면 구성을 확인하기 위한 예시 문구다. 실제 쥬빌리워십 송리스트로 확인된 정보가 아니다.

## 완료 기준

- 홈과 예배 상세에서 두 번 이내 조작으로 송리스트에 접근할 수 있다.
- 홈에서 별도 이동 없이 이번 주 예배 순서의 1~3번 곡을 확인할 수 있다.
- 초안이나 승인 전 목록은 공개되지 않는다.
- 곡 순서와 변경 상태가 명확하게 보인다.
- 공식 링크만 열리고 앱에서 가사·악보·음원을 무단 제공하지 않는다.
- 송리스트가 없거나 오류가 발생해도 빈 화면이 나타나지 않는다.
