# 이번 예배 말씀 기능

## 목적

쥬빌리워십 예배가 찬양과 설교로 구성된다는 점을 앱에 정확히 반영하고, 참석자가 예배 전에 설교 주제와 성경 본문 범위를 확인할 수 있게 한다.

## 사용자 화면

### 홈

- 다음 예배 카드 안에서 일시·장소 다음에 `이번 예배 말씀`을 표시한다.
- 공개된 설교 주제와 말씀 구절을 각각 한 줄로 요약한다.
- 정보 순서는 `예배 일정 → 설교 주제·말씀 구절 → 캘린더·길찾기 → 송리스트`로 유지한다.

### 예배

- 예배 카드에서 일시·장소·주소 다음, 송리스트 링크 전에 표시한다.
- 다가오는 예배와 지난 예배 모두 당시 공개된 설교 정보를 유지한다.
- 취소된 예배에는 설교 정보를 표시하지 않는다.

## 공개 정보

- 연결된 예배
- 설교 주제
- 말씀 구절: 성경책·장·절 표기
- 최종 공개 시각과 개정 번호

1차 앱에서는 성경 번역문 전문을 제공하지 않는다. 예: `요한복음 4:23–24`처럼 관리자가 확인한 본문 위치만 표시한다.

## 화면 상태

- 공개 완료: 설교 주제와 말씀 구절 표시
- 준비 중: `이번 예배 말씀을 준비하고 있습니다` 표시
- 변경 검수 중: 새 초안 대신 기존 공개본 유지
- 예배 취소: 설교 영역 숨김
- 불러오기 실패: 예배 정보는 유지하고 설교 영역에 다시 시도 안내

## 웹 관리자 운영

1. 기존 `예배 일정 관리`에서 대상 예배를 선택한다.
2. 별도의 `설교 정보` 영역에서 주제와 말씀 구절을 입력한다.
3. `editor`는 초안 저장과 검수 요청을 수행한다.
4. `owner`는 실제 설교 자료와 본문 표기를 확인하고 미리보기 후 공개한다.
5. 공개 후 수정하면 새 개정본을 만들며, 새 개정본이 승인될 때까지 기존 공개본을 유지한다.
6. 공개·교체·철회는 모두 오너의 건별 수동 승인으로 처리한다.

## 데이터 구조

`event_sermon_revisions`를 예배와 연결한다.

- `event_id`
- `revision_no`
- `sermon_topic`
- `scripture_reference`
- `status`: `draft`, `review_requested`, `published`, `withdrawn`
- 검수자·검수 시각
- 공개자·공개 시각
- 작성·수정 감사 기록

예배별 공개본은 최대 한 개만 허용한다. `owner` 전용 공개 함수가 기존 공개본 철회와 새 공개본 전환을 하나의 작업으로 처리한다.

공개 앱과 홈페이지에는 `public_events`를 통해 현재 공개된 다음 두 값만 전달한다.

- `sermon_topic`
- `scripture_reference`

초안, 관리자 식별자와 검수 기록은 공개하지 않는다.

## 입력 검증

- 설교 주제: 공백 제거 후 1~200자
- 말씀 구절: 공백 제거 후 1~300자
- 공개할 때 두 값 모두 필수
- 한국어 성경 권명과 복수 범위 표기가 다양하므로 정규식으로 신학적 정확성을 판정하지 않고 오너가 원문을 확인
- 실제 정보를 받기 전에는 production seed에 가상 설교 주제나 말씀 구절을 넣지 않음

## 1차 제외 범위

- 성경 번역문 전문
- 설교 원고
- 설교자 프로필
- 설교 음성 파일
- 설교 메모·댓글·북마크

## 완료 기준

- 홈과 예배 화면에서 동일한 공개 설교 정보가 표시된다.
- 한쪽 필드만 입력된 설교는 공개할 수 없다.
- 초안과 검수 요청본은 일반 사용자에게 노출되지 않는다.
- `editor`가 수정하는 동안 기존 공개본이 유지된다.
- `editor`의 직접 공개·철회와 승인 우회가 차단된다.
- `owner`가 공개하면 주제와 말씀 구절이 한 번에 교체된다.
- 설교 정보가 없어도 빈 화면이나 가상 정보가 나타나지 않는다.
